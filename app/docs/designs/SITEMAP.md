# Design Sitemap

## Admission rule for what is asserted as fact (added 2026-11-05 at the user's instruction)

Every factual premise in a concepts brief, design doc, review report or row below must arrive with one
of three tags. The full rule and its worked instances live with the defect record
(`project-sucr-open-defects.md`, `## Admission rule for records`); this is the design-side statement of it.

* **`writer:`** — name what can *put* the value there, not what reads it. A disjunction in the code is two
  claims, each needing its own producer. Both Feature 1 ruling 2's `network_id: None` half and the
  "double completion chime" were read off a correct local read with the writers never enumerated.
* **`predicate:`** — when a design borrows a mechanism (OS throttling, a Cargo profile, a packaging
  requirement), name the condition *it* keys on and measure that condition on this build, never a
  colloquial paraphrase of it. "The window is hidden" is not `document.visibilityState === 'hidden'`; the
  second was measured on 7 legs of the shipped 4,569,600 B exe under `SW_MINIMIZE`, `SW_HIDE` and the app's
  own close-to-tray, and read `'visible'` in all of them (`launched-exe run`, `design/completion-chime.md`).
  That is the scope of the claim: three hide mechanisms, this build, this WebView2 runtime — not "never".
* **`evidence-noun:`** — cite the type of evidence: `launched-exe run`, `unit test`, `grep`, `stat`,
  `counterfactual`, `user ruling`, `measurement`, with a locator. *Confirmed*, *verified*, *obvious*,
  *clearly*, *not a hypothesis* are not evidence and are banned as such — including in this file, whose
  previous section heading ("Verified numbers behind these documents") asserted confidence rather than
  provenance.

A claim that cannot carry a tag is a **question for a fresh-context lens**, not a premise. That is the
step this cycle already has, and it has falsified every owner-stated premise so far; the rule is only the
admission gate that keeps an un-tagged claim from reaching a draft as though it had passed.
