Bonding policy

How chunks are spread across bonded routes.

Metered connection guard

Keeps a mobile-broadband connection out of the bond.

Bonding is live: with two or more devices enabled, each chunk leaves bound to the address of the device that pulls it, and its row in the Chunks tab keeps that device's colour. One device is not a bond, so nothing is bound and Windows picks the route. The policy below decides what the workers do with those routes, and the metered guard holds a cellular device out of the pool entirely.

Proxy

Where Sucr's sockets leave. Direct is a decision, not an absence of one.

Address and bypasses

Manual only. http://proxy.corp:3128 or https:// with the same shape; a bare host:port is http. No password in the address — a proxy that asks for one is its own slice. Bypass entries are hosts: a name, an IP, or one * at either end. A subnet range is refused, because nothing would match it and the internal traffic would still go through the proxy.

Credential

A manual proxy only, and both halves commit together: to change one, type both; clear both to forget it. A system or environment proxy keeps whatever its own address already carries. What you type is saved in this app's library file exactly as written, not encrypted — the same file as your saved sessions.

Site credentials

For a link that answers 401. Sucr puts the credential on the request before the server asks for it. A password pair commits as one: to change either, type both; clear both to forget it. A bearer token is sent exactly as pasted, after the word Bearer, and its username box is not used. One host holds one credential, so a token replaces the pair saved for it. A host covers every port and path of it, and either kind is readable on the wire over plain http://. Saved in the library file exactly as written, not encrypted — the same file as your saved sessions.

Browser sessions

Some hosts only hand a link to a browser they have already cleared. Paste that browser's Cookie header and its user agent here; Sucr sends them to that host and to no other. The cookie is stored as pasted, in the library file. Cloudflare ties cf_clearance to the browser that earned it, so copy the user agent with it or the host refuses again.

Sucr Setup Guide Step 1 of 4

Choose Your Download Location

Pick a dedicated directory for your downloads. We strongly recommend choosing a secondary drive rather than your C: system drive.

Avoid defaulting to C:\Users\...\Downloads

Heavy downloads can rapidly exhaust your Windows OS drive, slow down system performance, and degrade SSD endurance. Storing on D:, E:, or a secondary drive keeps Windows fast and your files clean.
