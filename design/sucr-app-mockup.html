RuleWhy it exists
Motion is telemetryAn animation either reports real work or confirms a state change the user caused. Neither → no animation.
Max 2 ambient loops per screenPlexo's whole vocabulary is 4 keyframes and 2 matter. Both loops stop on blur, document.hidden and pause.
Never tween a live numberSpeed and byte counters update by replacement at ≤4 Hz. A tweened rate is a lie about now.
250 ms ceiling on anything waited onOnly the sucker map is allowed longer — it is watched, not waited on.
No glow, no gradient, no box-shadow animationPlexo's box-shadow: 0 0 7px on in-flight cells is replaced by fill + a brighter 1px border. Same signal, flat.
Reduced keeps the map usableIt is data, not chrome: cell-fill goes instant, cell-settle becomes a colour change, loops stop.

TierWhat it isExamplesDesign obligation
automaticThe engine decides. No setting, no action.block plan · stream doubling · hedging · refusal & disk ceilings · retry/backoff · Retry-After · sparse staging · collision suffixes · filename decoding · redirects · resume offsets · integrity samplingEvery decision observable and explainable — each writes a coded event and gets a Why?
policyChosen once in Settings, obeyed everywhere.global schedule · downloads-at-once · speed & data limits · proxy profile · capture filters · categories · autostart · notifications · themeA control in the inspector affects only the selection; one in Settings affects everything; a control in both states which wins.
actionThe user causes it, once.pause · resume · retry · cancel · remove · trash · fix link · choose torrent files · add download · start/stop queue · force/prevent keyReversible where possible; destructive ones name the file and the folder.
gatedNot a choice — a machine property.the eight probes aboveNever fail silently. Both reference apps fail here: Plexo degrades NIC binding without a word; the legacy one warns about admin mode only after a capture is lost.

The Why? column is the whole argument for building this product. Plexo already computes every one of these reasons and throws them away; the legacy one keeps a plaintext .log a curious user can open. Sucr structures it and puts it one click from the number it explains.
